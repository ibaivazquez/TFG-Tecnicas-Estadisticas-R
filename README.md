# TFG-Tecnicas-Estadisticas-R
TFG sobre técnicas estadísticas multivariantes en RStudio. Se introducen conceptos básicos de análisis de datos empresariales y se aplican Análisis de Componentes Principales, Análisis Factorial de Correspondencias Simples y Análisis de Correspondencias Múltiples a datos reales para ilustrar su utilidad en la exploración.
